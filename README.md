# XmlConverter
Тестовое задание с конвертером из похожего содержимого XML в конкретный вариант XML

Интерфейс приложения состоит из 3 частей. (скриншоты не грузит в гитхаб -_- )

Как пользоваться:
1. Управление файлом для загрузки. Принимает форматы представленные в ТЗ **data1**, **data2**, и они лежат в проекте в папке "Тестовое задание реформатор 2025"
2. Выбрали файл, нажали "Загрузить данные" -> верный формат обновилась левая таблица , где можно изменять данные или добавить новые по кнопке "Добавить запись". Так же запись можно удалить нажав напротив неё крестик.
3. Изменения сохранятся только если нажать кнопку "Сохранить"
4. После изменений или просто после загрузки файла можно нажать "Преобразовать", тогда заполнится правая таблица с информацией.
5. Любые изменения файлов для дополнительных отображений происходит через кнопку "Преобразовать"

Важно:
В ПО поддерживаются форматы только из **data1**, **data2** - где группировка идёт по месяцам, если написать аброкадабру, то выдаст ошибку неверных данных. 
Сама инструкция преобразования **instruction.xls** лежит в папке проекта и переварит аброкадабры

Дополнение:
90-95% кода сгенерировано ИИ. Для таких одностраничных проектов быстрее использовать инструменты для ускорения, чем самому каждую строчку писать.
